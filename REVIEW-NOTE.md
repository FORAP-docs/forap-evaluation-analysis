# Analysis software for anonymous review

This package contains the current analysis application, its tests and documentation, a synthetic demonstration workbook, and a blank questionnaire-data template. Follow README.md to install and run it locally. This is not an online hosted application.

Participant responses, optional contact information, study coding decisions, the study database, and private backups are not included. The supplied synthetic data contain 12 fictional responses. They demonstrate the software and do not reproduce the paper's findings.

The full questionnaire, approved codebook and six themes, aggregate results, response-distribution figures, and exploratory results are provided separately in the supplementary materials. The software does not preload the study's codes or themes.

The app's general comparison export includes all computed Tukey pairs and provides an omnibus-significance indicator. The paper's supplementary workbook retains only pairs following a significant omnibus ANOVA. Optional Holm sensitivity analysis is a software feature, not an analysis reported in the paper. Paper-reporting flags are assigned during preparation of the supplementary workbook, not inferred by the app.

This review snapshot includes the newer supplementary exports, theme controls, and database compatibility changes. No Git history or original repository location is included.
