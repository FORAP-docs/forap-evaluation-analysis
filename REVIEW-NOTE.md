# Analysis software for anonymous review

Follow `README.md` to install and run the application. The supplied Excel workbooks are a synthetic demonstration and a blank input template. Participant-level study responses are excluded because the consent did not authorize public data release. The original coding database is not included. Consequently, these files demonstrate the software and do not independently reproduce the paper's findings.

The separate `documentation-review.zip` contains the FORAP documentation snapshot and an anonymized blank questionnaire. No public repository, account, or Git history is required to use either package.
