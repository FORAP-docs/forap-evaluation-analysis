# Analysis software for anonymous review

Follow `README.md` to install and run the application. The supplied Excel workbooks are a synthetic demonstration and a blank input template. Participant-level study responses are excluded because consent did not authorize public data release. The original coding database is not included. These files demonstrate the software and do not independently reproduce the paper's findings.

The FORAP website is provided through a separate anonymous website link. The complete questionnaire, provisional codebook, and construct figures are prepared separately as supplementary PDF materials.
